that a journal reviewer will expect partly in the main body. For IJCB, double-blind anonymity is at risk: a web search
for the title returns a public GitHub repository under a personal account that carries the same title and paper draft
(see Dimension 1, item 9). Both are fixable in a day; they are listed as MAJOR, not as a scope flag.

Retrieval-grounded checks were run with WebSearch (five queries on beauty filters and deepfake detection, retouching
false alarms, identity-referenced detection, Celeb-DF-B follow-ups, and shortcut/augmentation bias). The three prior
evaluations the paper names (Libourel 2024, Saeed 2025, Concas 2025) are the closest works and are covered. One
directly relevant 2025 work on identity-referenced detection is missing (item 7 below). No other 2024-2026 paper was
found that measures both directions or tests the cause by training intervention, so the positioning stands.
