Prepared cases with known answers

Each case is drawn by a fixed random seed from the held-out sources, not chosen by hand. The verdicts are the detectors' real scores on these files. The aggregate numbers for each source are in the capstone report, so a single case never stands alone.

All cases come from research datasets whose images may not be redistributed (RetouchingFFHQ, Celeb-DF-B), so this page is shown only at the exhibition and is not part of any public copy; cases whose files are absent are hidden. Back to the live demo.
