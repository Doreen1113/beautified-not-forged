# 專題主張的兩個方向（2026-10-22，數字由腳本從結果檔產生）

一句話：偵測器把「美顏」和「偽造」混在一起，兩個方向都會錯：商用磨皮的真臉被判得比原圖更假；真實 App 美顏過的 deepfake 被放走。我們的三類模型兩邊都顧到。

## 不再主張的事
- Instagram AR 濾鏡（FairBeauty、B-LFW）：原圖沒經過同一套渲染管線，分不出濾鏡和管線；主模型與 RU9 都 75–78% 判假。
- 四種美顏操作的辨識：真實濾鏡上大眼 0.3%、瘦臉 3%、美白 18%、磨皮 24%（Addendum 55）；只在商用磨皮上可靠。
- LLM 改寫解釋：與模板句無差異，拿掉。
